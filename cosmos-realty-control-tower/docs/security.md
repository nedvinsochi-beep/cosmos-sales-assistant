# Безопасность

- Только входящий Bitrix24 webhook с минимальными правами чтения.
- URL webhook хранится только в локальном `.env`.
- Write-методы не принимаются клиентом.
- Логи содержат название метода, но не URL, параметры и ответы.
- Телефоны, email, имена, комментарии и пользовательские CRM-поля маскируются.
- Каталог `output/` исключён из Git.
- Тесты используют только синтетические записи.

## Запрещено до отдельного разрешения

Создавать, менять или удалять CRM-сущности, задачи, стадии и настройки; получать
или сохранять записи разговоров и тексты сообщений; отправлять клиентские данные
в GitHub или внешние AI-сервисы.

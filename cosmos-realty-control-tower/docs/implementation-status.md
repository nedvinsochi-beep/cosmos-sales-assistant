# Статус CR-BI-001–005

| Задача | Реализовано | Ограничение |
|---|---|---|
| CR-BI-001 | CLI инвентаризации методов, scopes и метаданных | Реальный запуск ждёт локальный webhook |
| CR-BI-002 | Python 3.12 проект, конфигурация, тесты, docs, schemas, output | Нет |
| CR-BI-003 | Read-only клиент, allowlist, пагинация, retry, timeout, rate limit, логи | Реальные доступные методы ещё не подтверждены |
| CR-BI-004 | Маскирование, metadata snapshot, синтетический demo snapshot | Снимок реальных записей не выполнялся |
| CR-BI-005 | Шесть правил, `BLOCKED_BY_DATA`, CSV/MD/JSON/HTML шаблоны | Нормативы и поля ждут подтверждения |

```bash
uv run cosmos-control audit-bitrix
```

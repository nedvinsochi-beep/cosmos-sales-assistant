# Статус CR-BI-001–010

| Задача | Реализовано | Ограничение |
|---|---|---|
| CR-BI-001 | CLI инвентаризации методов, scopes и метаданных | Выполнен live read-only аудит |
| CR-BI-002 | Python 3.12 проект, конфигурация, тесты, docs, schemas, output | Нет |
| CR-BI-003 | Read-only клиент, allowlist, пагинация, retry, timeout, rate limit, безопасные логи | Нет write-методов |
| CR-BI-004 | Маскирование, metadata snapshot, обезличенные live-выборки | Клиентские данные не выгружаются |
| CR-BI-005 | Правила, `BLOCKED_BY_DATA`, CSV/MD/JSON/HTML | Нормативы стадий ждут утверждения |
| CR-BI-006 | Структурный live-снимок лидов, сделок и активностей | Первый звонок заблокирован до утверждения provider ID |
| CR-BI-007 | Экран РОПа: сегодня, брокеры, воронка, контроль | Конверсии не выдумываются без истории стадий |
| CR-BI-008 | Отчёты по брокеру, отделу, РОПу и периоду | План-факт выводится только после подключения плана |
| CR-BI-009 | Dry-run сценарии напоминаний и эскалаций | Фактические уведомления не реализованы и не отправляются |
| CR-BI-010 | Demo/live режимы, тесты и документация | Нужна бизнес-приёмка нормативов |

## Одна команда после добавления секрета

```bash
uv run cosmos-control audit-bitrix
uv run cosmos-control report --department 2 --period week
```

Команда ничего не создаёт и не меняет в Bitrix24.

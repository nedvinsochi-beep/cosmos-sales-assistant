# Рабочий периметр РОПа

## Принцип

Дашборд по умолчанию показывает только группу A. Группы B, C и вся база
доступны отдельными переключателями в HTML. Это предотвращает смешивание живой
работы с историческим массивом.

## A. Оперативный контроль — 573 карточки

Предлагаемые критерии:

- карточка не закрыта;
- ответственный сотрудник активен;
- воронка не учебная/техническая;
- стадия не отнесена к прогреву или исключениям;
- создание, последняя CRM-активность или следующая задача попадают в последние
  7 дней.

В этой группе 514 карточек имеют хотя бы одно подтверждённое нарушение. Это
895 событий: 223 без следующей активности, 106 с просроченной активностью, 476
без активности 24+ часа и 90 «не принято» по тестовому определению.

## B. Прогрев / отложенная работа — 207 карточек

Предлагаемые критерии:

- 174 карточки находятся в статусах `PROCESSED`, `2` или `UC_ZL59WW`;
- 33 карточки имеют следующую дату касания позже оперативного 7-дневного окна.

Эти карточки должны иметь отдельный регламент частоты касаний. Они не должны
создавать ежедневные тревоги РОПу по тем же правилам, что новые лиды.

## C. Архив / исключения — 20 631 карточка

Состав:

- 6 416 закрытых карточек;
- 15 открытых карточек у неактивных сотрудников (всего у неактивных
  сотрудников найдено 309 карточек, остальные уже закрыты);
- 14 200 открытых исторических карточек без работы в предлагаемом 7-дневном
  окне.

Учебные категории `10` и `12` настроены как исключения, но в текущем полном
снимке сделок в них не найдено. Все 119 сделок относятся к категории `0`.

`Архив` здесь означает кандидат на исключение из ежедневного контроля, а не
разрешение закрыть или удалить запись.

## Фактические распределения

- открыто / закрыто: 14 995 / 6 416;
- сотрудники: 21 102 карточки у активных, 309 у неактивных;
- дата создания: 209 за 0–7 дней, 626 за 8–30, 11 881 за 31–90, 493 за
  91–180, 8 202 старше 180 дней;
- последняя активность: отсутствует у 10 849, была за 0–7 дней у 1 061,
  за 8–30 у 2 491;
- открытая следующая активность: есть у 637, отсутствует у 20 774;
- источники: `CALL` — 19 885, `RECOMMENDATION` — 1 151, остальные — 375.

Полная таблица по сущности, стадии, отделу, источнику, возрасту, сотруднику,
состоянию и следующей активности находится локально в
`output/calibration-summary.csv`.

## Переключатели

HTML-дашборд содержит ссылки:

- только оперативная работа;
- прогрев;
- архив;
- вся база.

CLI дополнительно поддерживает:

```bash
uv run cosmos-control report --work-scope operational
uv run cosmos-control report --work-scope warm
uv run cosmos-control report --work-scope archive --include-inactive-employees
uv run cosmos-control report --category 0 --department 22
uv run cosmos-control report --created-after 2026-07-01
uv run cosmos-control report --last-activity-after 2026-07-25
```

Также доступны фильтры РОП, брокер, источник, стадия и период.

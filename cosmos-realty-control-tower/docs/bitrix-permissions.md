# Права Bitrix24

## Фактическое состояние

Webhook работает от администратора и предоставляет 69 scopes и 1 160 методов.
Среди релевантных scopes доступны `crm`, `department`, `user`, `task`, `tasks`,
`tasks_extended`, `telephony`, `call`, `biconnector` и `timeman`.

Это технически широкий доступ, включающий не только чтение. Он безопасен в
этом проекте только благодаря явному allowlist в `BitrixClient`.

## Защита проекта

- URL webhook читается только из переменной окружения или локального `.env`.
- `.env` исключён из Git.
- Полный URL не пишется в прикладные логи.
- Неизвестный или write-метод блокируется до HTTP-запроса.
- Повторы выполняются только при сетевой ошибке, HTTP 429 или ошибке сервера.
- HTTP 4xx не повторяются автоматически.

## Рекомендация

Создать отдельного технического пользователя с минимальными правами чтения,
выпустить новый webhook и отозвать текущий административный ключ после
проверенного переключения. До этого использовать текущий ключ только через
allowlist-клиент.

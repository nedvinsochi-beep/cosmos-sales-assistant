# Словарь данных

Автоматически дополняется после первого разрешённого запуска аудита. Сейчас
реальные названия и ID полей не известны и намеренно не выдумываются.

| Сущность | Метод метаданных | Статус |
|---|---|---|
| Лид | `crm.lead.fields` | Требуется read-only подключение |
| Сделка | `crm.deal.fields` | Требуется read-only подключение |
| Активность CRM | `crm.activity.fields` | Требуется read-only подключение |
| Пользователь | `user.get` | Требуется проверка scope |
| Подразделение | `department.get` | Требуется проверка scope |
| Задача | `tasks.task.list` | Требуется проверка scope |
| Звонок | Не определён | Требуется инвентаризация телефонии |

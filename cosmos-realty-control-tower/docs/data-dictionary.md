# Словарь данных

Словарь основан на метаданных портала от 31 июля 2026 года. Значения клиентских
полей не выгружались.

## Лиды

| Поле | Тип | Назначение |
|---|---|---|
| `ID` | integer | Технический идентификатор |
| `STATUS_ID` | crm_status | Стадия лида |
| `SOURCE_ID` | crm_status | Источник |
| `ASSIGNED_BY_ID` | user | Ответственный |
| `DATE_CREATE` | datetime | Создание |
| `DATE_MODIFY` | datetime | Последнее изменение |
| `HAS_PHONE`, `HAS_EMAIL` | char | Только признак наличия контакта |
| `UTM_SOURCE`, `UTM_MEDIUM`, `UTM_CAMPAIGN` | string | Атрибуция рекламы |

Всего 78 полей, включая 20 пользовательских. Обнаружены поля семейства
`UF_CRM_AI_OKK_*` для оценки звонка, интереса, риска, следующего шага и статуса
проверки. Их значения в аудит не включались.

## Сделки

| Поле | Тип | Назначение |
|---|---|---|
| `ID` | integer | Технический идентификатор |
| `CATEGORY_ID` | crm_category | Воронка |
| `STAGE_ID` | crm_status | Стадия сделки |
| `SOURCE_ID` | crm_status | Источник |
| `ASSIGNED_BY_ID` | user | Ответственный |
| `DATE_CREATE`, `DATE_MODIFY` | datetime | Временные отметки |
| `CLOSEDATE` | date | Плановая дата завершения |
| `UTM_*` | string | Атрибуция рекламы |

Всего 69 полей, включая 21 пользовательское. Также обнаружено семейство
`UF_CRM_AI_OKK_*`.

## CRM-активности

| Поле | Тип | Назначение |
|---|---|---|
| `OWNER_TYPE_ID`, `OWNER_ID` | enum/integer | Связь с CRM-сущностью |
| `TYPE_ID`, `PROVIDER_ID` | enum/string | Вид и провайдер активности |
| `RESPONSIBLE_ID` | user | Ответственный |
| `DEADLINE` | datetime | Срок |
| `COMPLETED` | char | Признак завершения |

Всего подтверждено 44 поля. Темы, описания и коммуникации не сохраняются.

## Организационная структура

Подтверждено 13 подразделений: учредители, бухгалтерия, маркетинг, IT,
телемаркетинг, HR и несколько отделов продаж. Для BI требуется отдельно
утвердить, какие подразделения являются продажами и кто является их РОПом.

# Технический аудит Bitrix24

## Текущий статус

Реальное подключение не выполнялось: webhook отсутствует в репозитории и не
запрашивался из других проектов. Проект полностью готов к read-only запуску
командой:

```bash
uv run cosmos-control audit-bitrix
```

Команда проверит `app.info`, `scope`, список доступных методов и метаданные
полей лидов, сделок и активностей. Результат будет сохранён локально в
`output/technical-audit.json` с маскированием персональных данных.

## Уже подтверждено

- Источник по ТЗ: Bitrix24.
- Реальные портал, тариф, scopes, воронки, стадии, пользовательские поля,
  телефония и объёмы данных в этом репозитории не подтверждены.
- Все неподтверждённые проверки получают статус `BLOCKED_BY_DATA`.

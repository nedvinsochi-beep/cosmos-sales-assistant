# Cosmos Realty Sales Assistant

AI- и BI-система управления продажами Cosmos Realty на данных Bitrix24.

## Цель

Создать Control Tower, где:

- брокер видит личный рабочий экран;
- РОП управляет отделом по фактам;
- собственник контролирует РОПов и экономику;
- AI-аудитор выявляет нарушения CRM;
- AI-аналитик прогнозирует результат и предлагает решения.

## Безопасность

До завершения аудита работа ведется только в read-only режиме.

Запрещено без отдельного разрешения:

- изменять сущности Bitrix24;
- создавать или закрывать задачи;
- менять стадии;
- удалять данные;
- коммитить секреты;
- сохранять персональные данные клиентов в тестовых выгрузках.

## Первый этап

1. Аудит Bitrix24.
2. Карта данных.
3. Проверка качества CRM.
4. Минимальные отчеты РОПа.
5. Контроль РОПов для собственника.
6. AI-сводки после проверки метрик.
